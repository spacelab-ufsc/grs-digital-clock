\chapter{Introduction} \label{ch:introduction}

This document specifies the requirements for a custom-built digital clock to be installed in the SpaceLab\nomenclature{\textbf{SpaceLab}}{\textit{Space Technology Research Laboratory -- UFSC.}} UFSC ground station and control room. The clock is inspired by the Pro-Digital RDI-2M\nomenclature{\textbf{RDI-2M}}{\textit{Pro-Digital 6-digit industrial wall clock, medium model.}} industrial wall clock -- a 6-digit, Ethernet-synchronised display with ambient temperature alternation -- and must be designed, fabricated, and verified entirely in-house by the laboratory team.

The document also defines the work plan describing how the four-person team is organised, the tasks to be completed in each phase, and the expected deliverables per task.

\section{Scope}

The scope of this document covers:

\begin{itemize}
    \item A full set of requirements for all engineering disciplines: functional, physical, environmental, operational, interface, design, and mechanical.
    \item The GitHub\nomenclature{\textbf{GitHub}}{\textit{Web-based version control hosting service.}} repository structure and kick-off actions required before design work begins.
    \item A phased work plan for two hardware engineers and two firmware engineers working in parallel.
    \item Design constraints and notes that complement the formal requirements.
\end{itemize}
